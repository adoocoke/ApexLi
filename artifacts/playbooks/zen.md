# 缠论 Playbook v2.0 - Agent专用增强版（融合 czsc_skills 实战精华）
作者：基于缠中说禅原教旨 + czsc_skills 实战提炼 + Agent 使用优化

## 0. Agent 铁律（最高优先级，必须100%遵守）
0.1 **只做有明确结构支持的确定性机会**（分型-笔-线段-中枢-背驰/买卖点完整）
0.2 **无明确定式 → 坚决输出“观望”并解释原因**（绝不勉强）
0.3 **预测可以错，交易不能错** —— 永远只在能力圈内操作
0.4 **止损第一，保本离场是最高纪律**

## 1. 核心概念定义（Agent 判断依据）
1.1 **分型**：顶分型（高-低-高）、底分型（低-高-低），必须是有效分型（不被包含）
1.2 **笔**：由分型构成的不可被包含的K线段（方向一致，中间无包含）
1.3 **线段**：至少3笔 + 破坏原则（前一线段被破坏）
1.4 **中枢**：至少3段重叠部分形成的区间（高低点重叠）
1.5 **走势类型**：盘整（中枢延伸/扩张） vs 趋势（中枢新高/新低延续）

## 2. 背驰判断（最强武器，czsc_skills 核心）
2.1 **趋势背驰**：价格新高/新低，但 MACD 柱子面积或高度 < 前一段（或黄白线高度降低）
2.2 **盘整背驰**：中枢内价格创新高/新低，但力度减弱（成交量或 MACD 面积缩小）
2.3 **力度比较**：用 MACD 柱子面积、黄白线高度、成交量三者综合判断（czsc 推荐方法）
2.4 **区间套背驰**：次级别背驰 + 高级别背驰共振 = 极高概率

## 3. 三类买卖点（Agent 交易核心）
**一买/一卖**：中枢离开后第一类背驰（最强，优先级最高）
**二买/二卖**：中枢延伸后次级别背驰
**三买/三卖**：中枢被破坏后回抽不创新低/高（最稳，安全系数高）

3.1 只在**三类买卖点**中选择概率最高的执行
3.2 三卖后必须等三买确认才可考虑多头
3.3 结合 czsc_skills：优先找“区间套 + 背驰共振”的高胜率点

## 4. 操作纪律（Agent 必须执行）
4.1 无背驰或无买卖点 → 直接输出“观望”并详细解释
4.2 持仓期间出现次级别背驰 → 立即减仓或落袋
4.3 任何时候突破关键中枢高低点 → 立即止损/止盈
4.4 永远只做1-3笔结构清晰的品种，拒绝复杂混乱图形
4.5 严格执行“不参与不确定走势”

## 5. Agent专用思考模板（必须严格按此格式思考）
每次分析前内部思考并在输出中体现：
- 当前属于哪一级中枢？是否被破坏？
- 是否出现背驰？属于哪种背驰（趋势/盘整/区间套）？
- 是否形成三类买卖点？是第几类？概率如何？
- 当前最优操作是什么？（做多/做空/观望/减仓）
- 最符合哪一条具体规则？（必须写编号，如“2.1 + 3.2 + 4.3”）

## 6. Few-shot 示例（强烈推荐 LLM 参考）
示例1：价格新高但MACD柱子明显缩短 + 成交量萎缩  
→ “出现趋势背驰（2.1），属于一卖（3.1），建议空头进场，引用4.1坚决执行”

示例2：中枢被破坏后回抽不创新低 + 次级别背驰  
→ “形成三买（3.3），趋势反转概率高，结合区间套可考虑多头，引用0.3保本第一”
